AutoAssist para Empresas

Diagnóstico automotivo por foto, via API

Oficinas, seguradoras, inspectoras e marketplaces integram a IA da AutoAssist (modelo NOG) para gerar laudos a partir de uma foto. Cada chamada devolve diagnóstico em JSON ou PDF.

Ver documentação da API →

POST /api/b2b/diagnosis
Content-Type: application/json
 
{
  "image": "data:image/jpeg;base64,...",
  "format": "pdf"
}
 
→ 200 OK · laudo em < 3s

Como funciona

  • Crie uma API key de autoatendimento (trial gratuito com 100 chamadas ou planos pagos por volume).
  • Envie a imagem em base64 para POST /api/b2b/diagnosis.
  • Receba o laudo em JSON ou PDF pronto para anexar ao processo.
  • Acompanhe o consumo da sua cota por chave.

Segurança e conformidade (LGPD)

  • Imagens e laudos trafegam criptografados (TLS 1.2+) e em repouso.
  • Isolamento por API key; cada cliente acessa apenas seus próprios laudos.
  • Tratamento de dados conforme a LGPD; não treinamos modelos com dados de clientes B2B.
  • Retenção configurável e exclusão sob demanda para auditoria de seguradoras.
