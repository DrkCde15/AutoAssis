API B2B

Diagnóstico automotivo por foto, via API

Integre o AutoAssist ao seu sistema. Envie uma imagem e receba um diagnóstico completo em segundos.

Exemplo de chamada
curl -X POST https://api.autoassist-l9lr.onrender.com/api/b2b/diagnosis \
  -H "Authorization: Bearer sk_live_xxx" \
  -F "image=@painel.jpg"
Como funciona

4 passos para começar

01

Crie sua API Key

Cadastre-se e gere suas credenciais de acesso à API.

02

Envie a imagem

Faça POST de uma foto do painel ou componente para nosso endpoint.

03

Receba o relatório

Receba um diagnóstico estruturado em JSON com causas, severidade e sugestões.

04

Acompanhe o uso

Monitore suas chamadas no painel de controle em tempo real.
