Documentação da API

Tudo o que você precisa para integrar o AutoAssist ao seu sistema.

Base URL: https://api.autoassist-l9lr.onrender.comFormato: JSONAuth: Bearer Token

Autenticação

Todas as requisições devem incluir o header Authorization: Bearer <token>.

POST/api/b2b/authAutenticar e obter token de acesso

Diagnóstico

Envie uma imagem e receba um diagnóstico estruturado com causas, severidade e sugestões.

POST/api/b2b/diagnosis

Parâmetros

NomeTipoObrigatórioDescrição
imagefileSimImagem do painel ou componente (JPEG/PNG, max 10MB)
vehicle_makestringNãoMarca do veículo (ex: Toyota)
vehicle_modelstringNãoModelo do veículo (ex: Corolla)
vehicle_yearnumberNãoAno do veículo (ex: 2020)

Checkout

Crie uma sessão de pagamento para seus clientes.

POST/api/b2b/checkoutCriar sessão de pagamento

Leads

Liste os leads capturados pela sua integração.

GET/api/b2b/leadsListar leads capturados

Exemplo completo (cURL)

terminal
curl -X POST https://api.autoassist-l9lr.onrender.com/api/b2b/diagnosis \
  -H "Authorization: Bearer sk_live_xxx" \
  -H "Content-Type: multipart/form-data" \
  -F "image=@painel.jpg" \
  -F "vehicle_make=Toyota" \
  -F "vehicle_model=Corolla" \
  -F "vehicle_year=2020"

SDKs e exemplos

import requests

response = requests.post

  files={"image": open"painel.jpg","rb"}}

data = response.json()
