AutoAssist para Empresas

Diagnóstico automotivo por foto, via API

Oficinas, seguradoras, inspectoras e marketplaces integram a IA NOG para gerar laudos a partir de uma foto. Cada chamada devolve diagnóstico em JSON ou PDF.

Como funciona

  • Crie uma API key de autoatendimento (trial gratuito com 100 chamadas ou planos pagos por volume).
  • Envie a imagem em base64 para POST /api/b2b/diagnosis.
  • Receba o laudo em JSON ou PDF pronto para anexar ao processo.
  • Acompanhe o consumo da sua cota por chave.
