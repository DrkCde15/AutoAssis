Documentação da API de Laudo Automotivo

Transforme uma foto de veículo em laudo técnico via API. Envie a imagem em base64 para POST /api/b2b/diagnosis e receba o diagnóstico em JSON ou PDF em menos de 3 segundos.

← Voltar para a página B2B

Visão geral

Base URL  https://api.autoassist.com.br (substitua pelo seu domínio de produção)

Formato  JSON (application/json). O endpoint de diagnóstico também suporta resposta em PDF.

Auth  API key enviada no header X-API-Key. Crie sua chave pelo autoatendimento em b2b.html.

Autenticação

Toda chamada à API exige o header X-API-Key. Chaves inativas (ex.: plano pago ainda não pago) retornam 401.

POST /api/b2b/self-serve/keys Requer login (JWT)

Cria uma API key de autoatendimento (trial gratuito de 100 chamadas ou plano pago). A chave é exibida apenas uma vez.

Request
POST /api/b2b/self-serve/keys
Authorization: Bearer <SEU_JWT>
Content-Type: application/json

{
  "nome": "Oficina Centro Automotivo",
  "plan": "pro_5k"
}
Response 201
{
  "success": true,
  "plan": "pro_5k",
  "api_key": "aa_xxxxxxxxxxxxxxxx",
  "requests_limit": 5000,
  "rate_limit_per_min": 60,
  "aviso": "Guarde esta chave agora..."
}

Planos disponíveis: trial, pro_1k, pro_5k, pro_20k. Para planos pagos, use /api/b2b/self-serve/checkout para gerar a chave + link de pagamento Cakto.

Diagnóstico por foto

POST /api/b2b/diagnosis X-API-Key

Recebe uma imagem em base64 e devolve o laudo gerado pela IA. Suporta formato json (padrão) ou pdf.

Parâmetros (body JSON)

CampoTipoObrigatórioDescrição
imagestringSimImagem do veículo em base64 (data URI ou base64 puro). Máx. 15 MB.
perguntastringNãoPergunta específica sobre a imagem (ex.: "qual a gravidade desta avaria?").
formatostringNãojson (padrão) ou pdf.
Request (JSON)
POST /api/b2b/diagnosis
X-API-Key: aa_xxxxxxxxxxxxxxxx
Content-Type: application/json

{
  "image": "data:image/jpeg;base64,/9j/4AAQ...",
  "formato": "json"
}
Response 200 (JSON)
{
  "success": true,
  "client": "Oficina Centro",
  "formato": "json",
  "laudo": "Detectamos folga na...",
  "aviso": "Laudo gerado por IA..."
}

Resposta em PDF

Com "formato": "pdf", a resposta é um arquivo application/pdf anexado (laudo_autoassist.pdf), pronto para anexar a sinistros ou ordens de serviço.

{
  "image": "data:image/jpeg;base64,/9j/4AAQ...",
  "formato": "pdf"
}
Códigos de erro: 401 API key inválida/inativa · 400 campo image ausente · 413 imagem > 15 MB · 429 limite de taxa ou cota esgotada · 502 falha na análise.

Checkout de plano pago

POST /api/b2b/self-serve/checkout Requer login (JWT)

Cria a chave (inicialmente inativa) e retorna a URL de pagamento Cakto. A chave é ativada automaticamente via webhook após a confirmação.

Request
POST /api/b2b/self-serve/checkout
Authorization: Bearer <SEU_JWT>
Content-Type: application/json

{
  "nome": "Seguradora Exemplo",
  "plan": "pro_20k"
}
Response 201
{
  "success": true,
  "plan": "pro_20k",
  "api_key": "aa_xxxxxxxxxxxxxxxx",
  "checkout_url": "https://pay.cakto.com.br/...",
  "aviso": "Chave criada. Conclua o pagamento..."
}

Leads (contato enterprise)

POST /api/b2b/leads Público

Registra um contato para volumes acima de 20k chamadas/mês ou faturamento mensal.

POST /api/b2b/leads
Content-Type: application/json

{
  "nome": "Maria Silva",
  "email": "maria@seguradora.com",
  "empresa": "Seguradora Exemplo",
  "telefone": "11999999999",
  "mensagem": "Preciso de 50k chamadas/mês"
}

Resposta: 201 { "message": "Recebemos seu contato!..." }. Campos nome e email são obrigatórios.

Limites por plano

PlanoChamadas/mêsTaxa (req/min)Preço
trial10010Grátis
pro_1k1.00030R$ 49,90/mês
pro_5k5.00060R$ 149,90/mês
pro_20k20.000120R$ 399,90/mês

Ao exceder a taxa por minuto ou a cota mensal, o endpoint retorna 429. Volumes maiores: fale com o time B2B via /api/b2b/leads.

Exemplo completo (cURL)

# 1) Crie a chave (requer JWT de usuário logado)
curl -X POST https://api.autoassist.com.br/api/b2b/self-serve/keys \
  -H "Authorization: Bearer <SEU_JWT>" \
  -H "Content-Type: application/json" \
  -d '{"nome":"Oficina Centro","plan":"pro_5k"}'

# 2) Consuma o diagnóstico
curl -X POST https://api.autoassist.com.br/api/b2b/diagnosis \
  -H "X-API-Key: aa_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"image":"data:image/jpeg;base64,/9j/4AAQ...","formato":"pdf"}' \
  --output laudo.pdf
Interface interativa: a especificação OpenAPI está disponível em /api/docs e o Swagger UI em /api/swagger-ui.
